Every post is a Markdown file in `src/content/posts`. To publish a new one:

1. Copy this file and give it a new name, like `my-new-post.md`. The file name becomes the web address.
2. Change the title, description, date, and tags at the top.
3. Write the post below the dashes.
4. Commit the file to GitHub. The site rebuilds on its own in about a minute.

Set `draft: true` to keep a post hidden until it's ready. You can delete this post once you're comfortable.
